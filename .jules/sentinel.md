## 2024-06-17 - [DOMPurify & marked: Missing noopener noreferrer on external links]
**Vulnerability:** External links rendered via `marked` and sanitized by `DOMPurify` without explicitly configuring `target="_blank" rel="noopener noreferrer"` for external HTTP/HTTPS links expose users to `window.opener` vulnerabilities (TabNabbing) and privacy leaks, especially in a browser OS environment.
**Learning:** `DOMPurify` does not automatically add `rel="noopener noreferrer"` to anchors when `target="_blank"` is not present or when rendering arbitrary markdown. Overriding hooks globally in `DOMPurify` causes race conditions in React. Therefore, markdown external links must be explicitly intercepted during parsing.
**Prevention:** Whenever using `marked` to render untrusted markdown into HTML, use a custom `marked.Renderer()` that overrides the `link` method. Ensure external links (starting with `http://`, `https://`, or `//`) are injected with `target="_blank" rel="noopener noreferrer"` before the HTML string is passed to `DOMPurify`.
