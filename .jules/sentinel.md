## 2024-05-24 - [Reverse Tabnabbing Protection in Markdown Viewer]
**Vulnerability:** Reverse tabnabbing vulnerability in `MarkdownViewer` component where external links clicked could allow the opened window to exploit the `window.opener` object, potentially leading to phishing or executing malicious scripts.
**Learning:** Using `DOMPurify.sanitize()` without explicitly checking and enforcing `rel="noopener noreferrer"` for external anchor tags (`<a href="..." target="_blank">`) can expose the application to reverse tabnabbing. Furthermore, when dynamically adding `DOMPurify` hooks (e.g., `DOMPurify.addHook('afterSanitizeAttributes', ...)`), they MUST be removed immediately after sanitization (e.g., in a `finally` block) to prevent memory leaks and unintended side-effects on other DOMPurify sanitization calls throughout the app.
**Prevention:** Always secure external links with `target="_blank"` and `rel="noopener noreferrer"`. When employing `DOMPurify` hooks locally inside a component, ensure a safe cleanup using `DOMPurify.removeHook` within a `try...finally` structure.
